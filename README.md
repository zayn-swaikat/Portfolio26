# Zayn Swaikat — Developer Portfolio

> **Building digital experiences where logic meets imagination.**

A cinematic, interactive developer portfolio built to showcase my work across **Full-Stack Development, Data Analysis, and Creative Frontend Engineering**.

The portfolio combines structured engineering with expressive visual design, featuring immersive animations, interactive 3D elements, responsive layouts, and a hidden arcade game Easter egg.

**Live Portfolio:** https://zayn-swaikat.vercel.app/

## ✦ About

This portfolio is designed around the idea of **"The Variant"** — a personal visual language inspired by systems, alternate identities, controlled chaos, and experimentation.

Rather than presenting projects as a traditional list of cards, the site treats the portfolio as an interactive digital experience.

The goal is simple:

> **Show what I build — and make the experience of exploring it part of the story.**

## 🥚 Hidden Variant — BOUNCE

There is a hidden game inside the portfolio.

Find the secret interaction around:

```text

```

and you may discover **BOUNCE**.

### BOUNCE

A minimalist arcade game where the goal is to keep the ball alive for as long as possible.

The game features:

* Real-time score tracking
* High-score persistence
* Increasing difficulty
* Progressive ball speed
* Shrinking paddle
* Bounce counter
* Level progression
* Multiple ball skins
* Mouse controls
* Touch controls
* Responsive mobile gameplay
* Visual trails and impact effects
* Game-over statistics

**Play BOUNCE:** https://bounce-it-by-zayn.vercel.app/

The game is deployed independently from the portfolio so its Phaser runtime does not unnecessarily increase the main portfolio bundle.

## 🧠 Development Philosophy

My development process follows four main stages:

### 01 — Understand the Idea

Break the problem down before writing code.

### 02 — Design the Flow

Think about structure, hierarchy, UX, and interaction together.

### 03 — Build Clean Structure

Use reusable components, clear architecture, and maintainable code.

### 04 — Refine the Experience

Polish the details through animation, micro-interactions, responsiveness, and iteration.

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/zayn-swaikat/portfolio.git
```

Navigate into the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
